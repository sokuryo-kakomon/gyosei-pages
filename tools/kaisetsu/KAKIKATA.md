# 解説の書き方（行政書士 過去問ドリル）

## 基準
- **法令の基準日は 2026年4月1日施行の法令**（令和8年度試験の基準）。出題当時と今で答えが変わる肢・問は、`notice` に「改正」の札を書き、今の法令での答えを先に書く。正解はセンターの公表どおり（変えない）。
  - 例: `"notice": "法改正の注意：令和◯年の改正で〇〇が△△になったため、今の法令では肢2も妥当。出題当時の正解は3。"`
- 行政書士試験で特に注意する改正の例: 民事訴訟法の IT 化（令和4年改正・段階施行）、刑法の拘禁刑（2025-06-01 施行。懲役・禁錮は拘禁刑に一本化）、民法の親子法・共同親権（令和6年改正・2026-04-01 施行）、行政手続法・行政不服審査法・地方自治法の改正（地方自治法は令和6年の指示権の改正など）、会社法・商法の改正、個人情報保護法の改正。当たるか分からないときは `doubts` に書く。
- 条文は e-Gov の API v2 で日付を付けて引いて確かめる: `https://laws.e-gov.go.jp/api/2/law_data/<法令ID>?law_full_text_format=xml&asof=2026-04-01`（law_full_text は base64 の XML）。法令ID は `https://laws.e-gov.go.jp/api/2/laws?law_title=<名前>` で引ける。curl で取ってよい。
- 判例は「最大判昭和48年4月4日」「最判平成7年9月19日」のように、日付が確かなものだけ書く。確かめられなければ「判例」とだけ書く。判決文の言い回しを長く引かない（要旨を自分の言葉で）。
- 根拠の条文は「行政手続法第14条第1項」「民法第545条第1項」のように **第◯条** の形で（画面で e-Gov へのリンクになる）。法令名を省いた「第◯条」は、その前に出た法令名の条として読まれる。
- 基礎知識（問47〜57：政治・経済・社会・情報通信・個人情報保護・業務関連法令など）は、統計や時事の数字が古くなる。数字は出題当時の数字だと分かるように書き（「出題当時（令和5年）の統計では」）、今の数字が分からないものは書かない。

## 参考サイト
- 参考にしてよい（本人 11-09「解説は参考にはしてよ」）: 行書塾小野（gyosyo.info）・sak-office.jp/answer・合格道場（pro.goukakudojyo.com）など。根拠（条文・判例・論点）と各肢の正誤の確かめに使う。
- **自分の言葉で書く。** 参考サイトの解説文を写さない・言い換えだけの書き直しもしない（後で 8字の連なりで機械照合する）。

## 文
- だ・である調。1肢 1〜4文。結論（妥当／妥当でない、正しい／誤り）の理由を、どこが・なぜで書く。
- 問題文の引き写しは最小限に（肢を言い直すのではなく、理由を書く）。

## 出力（1問＝1要素・id は "r07-2" の形）
### 5肢択一（kind=choice）
```json
{
  "r07-2": {
    "lead": "何を問う問題かを1〜2文で。",
    "notice": null,
    "points": [
      {"k": "1", "v": "妥当", "t": "理由。根拠は行政手続法第14条第1項。"},
      {"k": "2", "v": "妥当でない", "t": "…"}
    ],
    "hint": "覚え所を1〜2文で。",
    "doubts": []
  }
}
```
- `points` は肢 1〜5 ごと。ア〜オを数える問・組み合わせる問は、ア〜オごとに書き、最後に `{"k": "結論", "v": "", "t": "妥当なものはア・エ。よって正解は2。"}` を足す。
- 語句の組合せの問（空欄ア〜オ）は、空欄ア〜オごとに入る語とその理由を書き、最後に結論。
- `v` は問いの言葉に合わせる: 妥当／妥当でない、正しい／誤り、など。
### 多肢選択（kind=tashi）
- `points` は空欄ア〜エごと: `{"k": "ア", "v": "8 先例", "t": "なぜその語が入るか（判例の流れ・条文）。"}`。lead で出典の判例・論点を一言。
### 記述（kind=kijutsu）
- `points` は採点の要点（キーワード）ごと: `{"k": "要点1", "v": "国を被告とする", "t": "なぜそれが要るか。"}` を2〜4個。
- 最後に `{"k": "書き方", "v": "", "t": "40字程度にまとめる順序とよくある失点（例: 被告を処分庁と書く）。"}`。
- センターの正解例（入力の model_answer）を写さない（画面に別に出る）。

- `answer` の正解（入力の answer。choice は番号、tashi は空欄ごとの語番号）が答えになる理由が通るように書く。自分の判断が公表の正解と違うときは、無理に合わせず `doubts` にその肢と理由を書く。
- `doubts`: 条番号が不確か、改正に当たるか分からない、正誤の判断が割れる、など。無ければ `[]`。
